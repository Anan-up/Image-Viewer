# 图片查看器 · Image Viewer

一个**纯本地、零上传、单文件**的网页图片查看器。整个应用压缩在一个 `image-viewer.html` 里，双击即可在浏览器中运行，无需服务器、无需构建、无需联网。

> 专注「看图」这一件事：多格式支持、自由缩放 / 平移 / 旋转、文件夹批量浏览。没有裁剪、涂鸦、滤镜等编辑功能。

## 快速开始

1. 下载 `image-viewer.html`（或解压 `image-viewer.zip` 得到它）。
2. 用浏览器打开该文件（双击，或拖入浏览器窗口）。
3. 把图片 / 整个文件夹拖进窗口，或点击「选择图片」「选择文件夹」。

无需安装任何依赖，也无需启动本地服务器。若希望通过 `http://` 访问（例如某些浏览器对 `file://` 的部分 API 有限制），可在该目录下跑任意静态服务器，例如：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/image-viewer.html
```

## 功能特性

| 分类 | 说明 |
|---|---|
| **多格式** | JPG / JPEG / PNG / GIF / WebP / SVG / BMP / ICO / AVIF / TIFF，取决于浏览器自身的解码能力 |
| **完全本地** | 图片经 `URL.createObjectURL` 直接读取，**不经过任何服务器、不上传** |
| **文件夹浏览** | 支持「选择整个文件夹」与「拖入文件夹」，自动递归展开子目录 |
| **自由缩放** | 滚轮 / 双指捏合 / 工具栏按钮，支持以指针为锚点的缩放 |
| **平移** | 按住拖动；触屏单指拖动 |
| **旋转** | 90° 步进旋转，旋转后自动重新适配窗口 |
| **适应 / 实际大小** | 一键在「适应窗口」与「1:1 原始像素」间切换 |
| **缩略图条** | 底部缩略图快速切换，可单独移除某张 |
| **沉浸模式** | 放大到图片溢出视口时自动隐藏上下工具栏，鼠标 / 手指移到屏幕边缘临时唤出 |
| **全屏** | 原生 Fullscreen API，含 `webkit` 前缀兜底 |
| **键盘无障碍** | 完整快捷键；缩略图 / 按钮支持 Tab 聚焦与读屏标签 |
| **平滑动画** | 缩放 / 旋转带缓动过渡，拖拽与捏合时自动关闭过渡以保持跟手 |

## 鼠标 / 触屏操作

**鼠标**

- 滚轮：以指针位置为中心缩放
- 按住左键拖动：平移
- 双击：在「适应窗口」与「实际大小」间切换
- 悬停缩略图右上角 `×`：移除该图
- 放大后把光标移到屏幕上 / 下边缘：临时唤出工具栏

**触屏**

- 单指拖动：平移
- 双指捏合：缩放（以双指中点为锚点，并叠加双指整体平移）
- 放大后手指抵达上 / 下边缘：临时唤出工具栏

## 隐私与安全

- **零上传**：图片通过 `URL.createObjectURL(file)` 生成本地对象 URL 直接喂给 `<img>`，数据从不离开本机。
- **零网络**：单文件不含任何外部请求（无 CDN、无字体、无埋点）。
- **资源回收**：页面卸载（`pagehide` 且非 bfcache 场景）时统一 `revokeObjectURL`，避免内存泄漏。

## 浏览器支持

面向所有现代浏览器（Chromium / Firefox / Safari 及移动端）：

- 使用 `ResizeObserver` 缓存几何信息，避免每帧强制同步布局。
- 全屏 API 同时绑定标准事件与 `webkitfullscreenchange`。
- 拖入文件夹用 `webkitGetAsEntry()` 递归读取（现代浏览器普遍支持）。

## 技术实现

几个关键设计点，便于后续维护：

### 1. 单一变换，原点固定在左上角

所有缩放 / 平移 / 旋转合成为一个 CSS `transform`：

```css
.stage { transform-origin: 0 0; }
```

```js
stage.style.transform =
  `translate(${tx}px, ${ty}px) scale(${scale}) rotate(${rot}deg)`;
```

图片在 `.stage` 内用 `translate(-50%,-50%)` 自居中，使 `(tx, ty)` 恒等于「视口坐标系中的图片中心」，缩放 / 旋转数学因此完全解耦。

### 2. 以指针为锚点的缩放

设指针屏幕坐标 `m`、当前平移 `T`、缩放倍率 `k`：

```
T' = m - k · (m - T)
```

该式保证指针下的图像点在缩放前后位置不变（`k = 1` 时恒等，无跳变）。

### 3. 尺寸缓存，消除每帧布局抖动

```js
let vp  = { left, top, w, h };   // 视口矩形（getBoundingClientRect），由 ResizeObserver 维护
let win = { w, h };              // 窗口尺寸
const BAR = 54;                  // 顶部工具栏高度
```

拖拽 / 捏合的 `pointermove` 只读缓存，不触发强制同步布局。

### 4. 适应比例与沉浸态解耦（避免循环抖动）

`computeFitScale()` 的**基准高度固定为 `win.h - BAR`**（即非沉浸态视口高度），而不是实时的 `vp.h`：

```js
function computeFitScale(){
  const rotated = ((rot % 180) + 360) % 180 === 90;
  const w = rotated ? imgDim.h : imgDim.w;
  const h = rotated ? imgDim.w : imgDim.h;
  return Math.min(win.w / w, Math.max(0, win.h - BAR) / h);
}
```

否则会形成死循环：进入沉浸态 → 视口变高 → `fitScale` 变大 → 「已放大」判定翻转 → 退出沉浸态 → ……导致工具栏闪烁。它与 `updateChrome()` 的判据、`lastWasFit` 的判定统一走 `fitScaleClamped()`（即再受 `MIN_SCALE` / `MAX_SCALE` 约束），保证三者口径一致。

### 5. 手势状态机

`pointers: Map<pointerId, {x, y}>` 跟踪全部指针，并按数量分派：

| 指针数 | 行为 |
|---|---|
| 1 | 平移 |
| 2 | 捏合缩放 |
| ≥3 | 忽略多余手指，冻结当前缩放基线（避免抖动） |

松开时逐级降档：`3 → 2` 无条件重建捏合基线，`2 → 1` 转为平移，`1 → 0` 结束手势并恢复过渡动画，杜绝「既不拖也不缩」的冻结态。

## 已知边界与取舍

- **`fit()` 在沉浸态有一帧偏上**：缩放按 `win.h - BAR`，居中按实际 `vp.h`，进入 / 退出沉浸的瞬间可能有一帧轻微偏移，退出后即一致，肉眼几乎不可见。
- **拖入文件与文件夹选择器的去重**：去重键含 `webkitRelativePath`，因此「文件夹选择器」与「直接拖入同名文件」可能被视作两条记录（拖入时该路径为空）。
- **新增图片为追加而非全局重排**：多次加载时新图追加在末尾（各自内部有序），不改变已加载项的顺序，以免使 `state.index` 失效。
- **`MAX_SCALE` 上限**：极小图片（如 2×2 图标）适应窗口时会被限制在 `60×`，而非按比例放大到夸张倍数。

## 常见问题

**Q：会把我选择或查看的图片上传吗？**
不会。全程使用本地对象 URL，代码中不存在任何上传 / 网络请求逻辑。可断网使用。

**Q：为什么某些图片打不开？**
解码由浏览器决定，例如部分浏览器不支持 TIFF / AVIF。损坏或不支持的文件会被自动跳过。

**Q：图标要不要放进 zip？**
不需要。图标全部是内联 SVG，无外部资源。

**Q：想改快捷键 / 缩放步长？**
搜索 `MIN_SCALE` / `MAX_SCALE`（缩放范围）、`1.15` / `1.3`（滚轮与按钮步长）、以及文件末尾的 `keydown` 监听（快捷键映射）即可。
